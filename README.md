# ☕ Tomoro Coffee WiFi Landing Page

Landing page sederhana untuk akses WiFi di Tomoro Coffee Mulyosari.
Digunakan melalui QR Code untuk memudahkan pelanggan terhubung ke WiFi sekaligus melihat promo.

---

## 📶 Fitur Utama

* Connect WiFi dengan bantuan tombol
* Copy password WiFi
* Redirect ke halaman promo / Instagram
* Tampilan responsive (HP & Desktop)
* UI clean dengan branding Tomoro Coffee

---

## 🚀 Cara Pakai

1. Scan QR Code yang tersedia di meja
2. Buka landing page
3. Klik tombol **Connect WiFi**
4. Ikuti instruksi untuk terhubung ke WiFi

---

## 🛠️ Teknologi

* HTML
* CSS
* JavaScript

---

## ⚙️ Konfigurasi

Silakan edit bagian berikut di `index.html`:

### SSID & Password

```html
SSID: Tommunity Mulyosari
Password: PesanDulu
```

### Redirect Promo

```javascript
window.location.href = "https://instagram.com/tomorocoffee.id";
```
